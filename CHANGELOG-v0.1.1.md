# Tubbie v0.1.1

A small update over [v0.1.0](../../releases/tag/v0.1.0) — installed clients receive this automatically via Settings → Updates.

## Changes

- **Default station on first launch is now Oxford Circus** (was Belsize Park). If you've already saved a station, your choice is preserved — this only affects fresh installs.

## Install

If you're running v0.1.0: just open Tubbie and let the in-app updater take it from here. Settings → Updates → Check for updates → Install and restart.

If you're installing fresh: grab `Tubbie_0.1.1_aarch64.dmg` below, mount it, drag Tubbie to `/Applications`. Signed + notarized — Gatekeeper accepts it on first run.
