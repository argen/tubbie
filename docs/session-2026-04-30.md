## Cross-repo line-id canonicalisation contract

After this session, every `line_id` that crosses the Rust → TS boundary uses the **line form** (`"elizabeth"`), never the mode form (`"elizabeth-line"`). The mode form is contained to two TfL endpoints we never expose:

- `/StopPoint/{id}/Arrivals` — canonicalised in `Arrival::deserialize`.
- `/Line/Mode/{mode}/Status` — canonicalised in `TflLine::deserialize`.

Settings stores the line form; chips render the line form; the frontend filter compares the line form. Any historical `"elizabeth-line"` in a saved config is migrated on `load_config` (both apps).

If a third TfL endpoint ever returns yet another form, add the alias to `tfl_domain::canonicalize_line_id` and every consumer picks it up.
