# Architectural Decision Records

ADRs are primarily for AI agents consuming prior decisions so they don't re-litigate settled choices.
Each ADR captures **Context / Decision / Consequences / Status**.

Filenames never contain numbers — the table below is the only place numbers live.
To supersede an ADR: update its Status field; never renumber or rename.
